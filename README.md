# Carnet de délégation

Application de suivi personnel des heures de délégation (`delegation/index.html`) :

- crédit mensuel par mandat (CSE, DS, CSSCT… paramétrables selon votre accord) ;
- report des heures non utilisées sur 12 mois, plafonné à 1,5 fois le crédit (R2315-5) ;
- mutualisation reçue / cédée (R2315-6) ;
- heures hors crédit (réunions à l'initiative de la direction, enquêtes AT/MP, DGI, formation, trajets – L2315-11) ;
- heures prises sur repos à récupérer ou payer, avec case « vérifié en paie » ;
- export CSV (Excel, séparateur `;`) et sauvegarde / restauration JSON.

Publiée comme Artifact claude.ai (stockage privé lié au compte). Ouverte hors claude.ai, elle enregistre dans le navigateur.
